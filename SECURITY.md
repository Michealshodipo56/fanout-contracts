# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability in Fanout smart contracts, please report it immediately to security@fanout.network or open a security disclosure advisory.

**Do not report financial contract vulnerabilities via public GitHub issues.**

## Scope & Audit Status

- **Status**: Pre-audit / Stellar Wave Submission Candidate.
- **Tested**: Comprehensive unit tests, property tests, and replay protection checks.
