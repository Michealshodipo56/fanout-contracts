# Contributor Covenant Code of Conduct

We pledge to make participation in Fanout a harassment-free experience for everyone. Be respectful, accept constructive feedback, and focus on safe, correct outcomes for users. Harassment, discrimination, threats, and publishing private information are unacceptable.

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may remove content or restrict participation when behavior is inappropriate or harmful. This policy is adapted from the Contributor Covenant, version 2.1.
